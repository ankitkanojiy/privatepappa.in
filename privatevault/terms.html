App Description

PrivateVault (Free) is an offline encrypted file vault for Android, published by Privatepappain. It helps you store and manage personal files locally on your device, focusing on local privacy, file organization, and secure image viewing — without cloud accounts, telemetry, or online file viewers. The Free edition shows ads and uses network access only to show them, never to handle your files.

The app uses industry-standard AES-256 encryption in GCM mode so that imported files cannot be read without proper local authentication. Encryption keys are generated and stored securely on your device using key derivation functions like PBKDF2 or Argon2.

Key Features

  • Offline encrypted file vault (AES-256-GCM)
  • Local-only file storage and management
  • In-app secure image viewer
  • Import, export, share, and open-with
  • Password and biometric unlock, auto-lock
  • Password-protected encrypted backup creation
  • Screenshot protection for sensitive screens
  • No cloud account required; no telemetry or analytics
  • Ad-supported

Limitations

PrivateVault cannot guarantee that every file type will preview or render perfectly. Unsupported, corrupted, extremely large, or password-protected files may fail to open, preview, or process.

Screenshot protection and app obfuscation reduce risk but cannot provide absolute protection against rooted devices, compromised systems, external cameras, screen mirroring bypasses, malware, or advanced reverse engineering.

PrivateVault does not provide cloud recovery, server-side password reset, or developer recovery access. If a vault password is forgotten or lost, encrypted files may be permanently inaccessible.

Encryption itself does not damage files. The real risk is an interrupted or incomplete write — caused by the phone powering off, storage running out, the app being force-closed, or cleaner apps modifying vault data. PrivateVault uses authenticated encryption, which means even one altered byte will cause the app to block access to that file as a safety feature.
