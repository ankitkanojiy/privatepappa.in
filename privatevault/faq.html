PrivateVault FAQ

Answers about PrivateVault (Free): the offline vault, encryption, permissions, ads, and the image viewer.

Free vs PRO

What's the difference between PrivateVault and PrivateVault PRO?

PrivateVault (Free) includes the essential offline encrypted vault: importing and encrypting files, exporting when needed, password and biometric unlock, an in-app secure image viewer, search and sorting, delete, activity logs, auto-lock, password changes, vault reset, encrypted backup creation, sharing, and open-with. PrivateVault PRO adds in-app viewers for all file types, scan-to-PDF, folders, move/rename, starred files, restore, vault health, dark theme, text/code editing, Panic Lock, an optional end-to-end-encrypted Cloud Vault backup, and more — and it is ad-free.

Offline

Does the Free version work offline?

Yes. The vault itself works offline — your files are encrypted and stored on your device. The Free edition shows ads, so it uses network access only to load those ads, never to upload or sync your files.

Ads

Why does the Free version show ads, and what data do they use?

Ads support development, which is why the Free edition needs network access. The app requests non-personalized ads by default. The ad provider collects advertising identifiers, coarse IP-based location, and ad-interaction data; your encrypted files and vault data are never shared with advertisers. PrivateVault PRO is completely ad-free.

No cloud

Are my files uploaded anywhere?

No. Vault files remain local unless you manually export or share them. The app has no cloud sync and no developer servers for your vault.

Encryption

How are files protected?

Files are stored encrypted using AES-256-GCM with PBKDF2 key derivation, SHA-256 integrity hashing, and chunk-level authentication. All encryption and decryption happens locally on your device. Encryption is identical in the Free and PRO versions.

Images

Can I view images in the Free version?

Yes. The Free version includes an in-app secure image viewer — view, zoom, and pan images inside the vault. Images are decrypted only in memory and never written outside the vault. Other file types (video, audio, PDF, documents, code) require PrivateVault PRO.

Permissions

Which permissions does the Free app use?

Only what's needed: import uses Android's document picker (Storage Access Framework), so no broad media/storage permission is requested; camera/microphone only for optional in-app capture; and INTERNET only to show ads.

Unlock

How do I unlock the vault?

With a vault password (up to 127 characters) or your device biometrics. Auto-lock re-secures the vault when you leave the app.

Backup

Can I back up my vault?

Yes. PrivateVault can create a password-protected encrypted backup. Keep the backup password safe — it is required to restore. (Restoring a backup is a PrivateVault PRO feature.)

Upgrade

How do I move to PrivateVault PRO?

Create a password-protected encrypted backup in PrivateVault, then open PrivateVault PRO, choose Restore, select that backup, and enter the same backup password. No cloud transfer is involved.

Security

What if I forget my vault or backup password?

The password is required to unlock the vault or restore a backup. There are no servers for your vault, so there is no server-side recovery. Keep your password safe.

Data safety

Can encryption damage my files?

No. The real risk is an interrupted write (phone powering off, storage running out, force-closing the app, or cleaner apps modifying vault data). Authenticated encryption blocks access to incomplete or altered data as a safety feature. Keep your device charged and don't manually modify the app's internal files.

Feature Availability Note

Some features depend on device capabilities, Android version, supported file types, and production build configuration. Not every feature will be available on every device or for every file format.
