Overview

PrivateVault PRO is a fully offline encrypted vault app for Android, published by Privatepappain. It has no network permission, contains no ads, and uses no analytics, advertising, or tracking SDKs. Your vault contents are encrypted and managed entirely on your device and are never collected, uploaded, or shared.

Data Collection

PrivateVault PRO collects no user data. There is no cloud sync, no telemetry, and no network permission, so there is no mechanism for the app to transmit anything off your device. In particular, the app does not collect:

  • Photos, videos, audio, or documents stored in your vault
  • Vault passwords or encryption keys
  • Contacts, messages, or call logs
  • Location of any kind
  • Advertising identifiers (there are no ads)
  • Behavioral analytics, usage tracking, or crash analytics

Permissions & File Access

PrivateVault PRO requests only permissions needed for user-selected features:

  • File and folder import uses Android's Storage Access Framework (the system document/folder picker), so no broad media or storage read permissions are requested.
  • CAMERA is requested only when you choose in-app document scanning.
  • No INTERNET or network-state permission is requested. The app cannot connect to the internet.

How Data Is Used

Files you select are used locally to provide vault features, including encryption, decryption, local preview and viewers, local thumbnails, local search, scan-to-PDF, export, sharing, and organization. Nothing is sent to the developer or any server because the app has no network access.

Sharing & Disclosure

PrivateVault PRO shares no data. Files leave the app only when you explicitly export or share decrypted files using your device's storage picker or the Android share sheet.

Security

The app uses industry-standard AES-256 encryption applied in secure modes such as AES-GCM, providing both confidentiality and integrity. Encryption keys are derived locally using hardened key derivation functions such as PBKDF2 or Argon2. All encryption, decryption, and key storage happen entirely on your device. Additional layers include secure vault sessions, protected previews and viewers, screenshot blocking on sensitive screens, Panic Lock, and temporary file cleanup.

Children's Privacy

PrivateVault PRO is not directed to children under 13 and does not knowingly collect personal information from children.

Data Safety Summary

  • Data collected: None
  • Data shared: None
  • Data sold: No
  • Cloud sync: None
  • Ads: None — the app has no network permission
