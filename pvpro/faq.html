PrivateVault PRO FAQ

Answers about PrivateVault PRO: offline-first operation, the optional Cloud Vault, in-app viewers, scanning, restore, and more.

Offline

Is PrivateVault PRO offline?

PRO is offline-first and ad-free: there is no ad SDK, and your vault is encrypted and stored on your device by default. The only time it uses the network is the optional Cloud Vault — if you turn it on, it backs up end-to-end-encrypted data to your own Google Drive. Your files are encrypted on-device before any upload, and the developer can never read them. If you never enable Cloud Vault, the app never contacts the network with your data.

Free vs PRO

How is PRO different from the free PrivateVault?

Both use the same AES-256-GCM encryption. PRO adds in-app viewers for all file types, scan-to-PDF, folders, move/rename, starred files, restore, vault health, dark theme, text/code editing, Panic Lock, and an optional end-to-end-encrypted Cloud Vault — and it removes ads. See the free version for the baseline.

Ads

Does PRO show ads?

No. PRO is completely ad-free and contains no advertising SDK.

Cloud Vault

What is Cloud Vault, and is my Google Drive safe?

Cloud Vault is an optional backup that is off by default. When you enable it, you connect your own Google account and PRO backs up your vault to the app's private folder in your Google Drive. It uses only the drive.appdata scope, so it cannot see or touch any other file in your Drive. Everything is end-to-end encrypted on your device first, with keys that never leave your device — so Google and the developer cannot read it. You can delete backups or unlink your account at any time.

Viewers

Which file types can I view in PRO?

Images, video, audio, PDFs, documents, archives, and code/text can be viewed inside the vault. Files are decrypted only in memory for display. Office document viewing beyond PDF and text/code may be added in future updates.

Scanner

Can I scan documents?

Yes. PRO includes camera document scanning with basic crop, saved straight into the encrypted vault as a PDF. Camera permission is requested only when you use scanning.

Restore

Can PRO restore a backup from the free app?

Yes. PRO can restore the encrypted backup files created by PrivateVault (Free). Use the same backup password that was used when creating the backup.

Code

Can I edit code and text files?

Yes. PRO supports viewing and plain-text editing of common code formats (JavaScript, TypeScript, C, C++, Java, PHP, Python, Kotlin, Swift, HTML, CSS, JSON, XML, YAML and more), with autosave and preserve-originals so you can restore the original later.

Password PDFs

Can I open password-protected PDFs?

Yes. PRO can open supported password-protected PDFs inside the vault with session isolation. Passwords are not stored.

Security

What if I forget my vault password?

The password is required to unlock the vault. The developer runs no servers that can decrypt your data — even your Cloud Vault backup is end-to-end encrypted — so there is no server-side recovery. Keep your password and recovery key safe and maintain your own encrypted backups.

Data safety

Can encryption damage my files?

No. The real risk is an interrupted write (phone powering off, storage running out, force-closing the app, or cleaner apps modifying vault data). Authenticated encryption blocks access to incomplete or altered data as a safety feature. Keep your device charged and don't manually modify the app's internal files.

Purchase

How do I buy PRO, and can I get a refund?

PRO is a paid app on Google Play. Pricing, payment, and refunds are handled by Google Play under its own terms — review Google Play's refund policy before purchasing.

Feature Availability Note

Some features depend on device capabilities, Android version, supported file types, and production build configuration. Not every feature will be available on every device or for every file format.
